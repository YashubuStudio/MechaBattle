## 2. ブラッシュアップ案（短期・既存機能の磨き込み）

### A. 戦闘の手応え（COMBAT-02/AIM-03/FIELD-04は完了・ユーザー実戦確認済み）
前方シールド・5格闘（専用装備化・溜め/踏み込み/連撃キャンセル）・DP（よろけ/転倒）・装備10種（装填/発射後回復/実弾速/赤黄ロック）・照準修正・壁/ジャンプ/頭部一人称まで実装が完了。残る確認観点:
- **対応済み**: 本拠点の建屋反撃（範囲攻撃）は盾を貫通する仕様で確定しており、`baseCounterFireDamage`は105→70（HP100の7割、シールド非依存）へ修正済み（本セッションで実施、GPTも受領・保持を確認）。
- **対応済み**: 射撃6方式は武器別の物理射程/実弾速/赤黄ロックを持つ（継続ビームのみ即時照射）。当初の課題だった「全武器ヒットスキャン」はFIELD-04で解消。
- 被弾時のフィードバック（画面の振動、ダメージ方向表示）は音のみ。視覚フィードバックの追加を検討（優先度：低〜中）。

### B. UI/操作性
- 赤ロック（BOT→人間のみ短縮）はSimulation側に実装済みだが、PlayableのHUDには表示されていない。自分が狙われやすい状態であることを示すインジケーターがあると、設計意図（対人優遇）が体感しやすくなる（優先度：低）。
- ミニマップ・HUDは機能面では十分だが見た目はプレースホルダー。実際のプレイ感が固まってから調整するのが効率的（優先度：低、後回し推奨）。

### C. BOTの行動パターン
- **対応済み**: 中継拠点を**意図的に**取りに行く挙動を実装済み（自軍未所有の中継拠点を優先し、所有済みなら本拠点へ進む）。GPTが実プレイ画面側にも配線し、弾切れは占領より帰還を優先する等の優先順位も検証済み。
- 残課題: 本拠点を**守る**（敵が自軍拠点を狙っている時に戻る）、体力が減ったら離脱する、といった行動はまだ無い（HPベースの判断には`SelfObservation`へのHealth追加が必要で、共有契約ファイルのため次の安全な統合タイミングで対応）。GPTからも「中継の所有切替で全機が何度も引き返す傾向」が確認候補として挙がっている。

### D. コンテンツ量
- 標準マップが1種類のみ（p0-three-lanes）。構築カタログは装備10種まで拡充済み（FIELD-04）だが、フレーム自体は1種類のみ。ブラッシュアップとしては優先度低（まずゲームループの手応えを固めるのが先）だが、将来のコンテンツ拡充リストとして記録。モデルも`MB_Worker01`1種類のみ（手続き生成パイプラインは既にあるため、見た目バリエーション追加は低コスト）。

## 3. 優先して着手すべきこと（ブラッシュアップではなく実施事項）

1. ~~本拠点ダメージの再調整~~: **対応済み**（105→70、GPTも受領・保持を確認）。
2. **性能計測（NFR-001/T-013）**: 100機同時稼働時の実機FPS/GC/CPU/GPU計測が一度も行われていない。P0の受入条件そのものであり、FIELD-04が一区切りついた今が実施の好機。Windowsビルド（`MechaBattle > Playable > Build Windows Playable`）を実行し、実機で計測する。
3. **GPT差分レビュー**: BattleTraversal/BattleInventory/BattleDeployables/BattleCombat、PlayableEntryのカメラ/ロック/入力、ConstructionEvaluator/UnitLoadout、実JSON/ModelToolsのレビューをGPTから依頼されている。次の着手事項。

## 4. 中期ロードマップ（P3〜P5への橋渡し）

- **P3 小隊AI（提案フェーズ分け）**:
  1. 4機の小隊をグルーピングするだけの最小実装（個体の意思決定は変えず、移動先だけ共有）
  2. 役割分担（前衛/支援/強襲など）の導入
  3. 作戦プリセット（RushBase, Diversion, FocusFireなど、SYSTEM_DESIGN §10.2に記載済み）
- **P4 指揮官AI（提案フェーズ分け）**:
  1. TeamKnowledge（非全知の観測集計）の実装 — 現状は「自分の武器射程内なら敵の真の位置を見る」という最小限のハックのみで、本来の「視界・索敵・認知遅延」モデルが存在しない。指揮官AIを作る前にここを固める必要がある。
  2. 指揮官の静的な作戦選択（どの本拠点を守るか、どこを攻めるか）
  3. 一斉凸カウントダウン・陽動ピンのUI表示（プレイヤーへの強制力なし、情報提供のみ）
- **P5 演出と調整**:
  - 本格的な音響（現在は合成音のみ）
  - マップ追加・地形ギミック
  - アートの密度向上（現在は単一の簡易ロボットのみ）
