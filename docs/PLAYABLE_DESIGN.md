# プレイ版の設計と受入条件

Windows x64、1人+99BOT、100操縦枠＋各軍1指揮官枠、各軍3本拠点。IPを除くシステムは機動戦士ガンダムオンラインを基本とし、最新のユーザー指定を優先する。小隊/指揮官AIの実戦判断、金功績、戦略核、オンライン等の全計画完成とは区別する。

| 画面・機能 | 実装 |
|---|---|
| 準備・格納庫 | 軍/4機デッキの選択を強調。左右腕/3装備は一覧から直接選択。装備中の印、役割別説明、性能/容量/自動コスト/CT、選択装備のプレビュー |
| 戦闘 | Spaceジャンプ/Shiftダッシュ、自由照準、ホイール/1〜3。広い円＋中心十字、命中確度の円色、胴体の菱形/距離/赤黄状態 |
| 手動ロック | メイン/参戦準備/休止で中心優先・距離順切替を設定。右クリック取得/解除、Tab切替、機体優先の設置物ロック。回復FA/ポッド所持なら味方も候補、回復FA選択中は味方のみ。物理>黄>赤。敵ロック中の攻撃武器は散布0の直進弾。赤で手動取得時だけ瞬間吸着、その後の照準・カメラは自由。継続誘導なし |
| HUD | 3枚の装備カード、射程/弾速、HP/盾/残弾/装填/溜め/ブースト/DP、被弾/低HP/行動阻害、被ロック数/警告音/ロック相手から被弾した際の退避案内、ゲージ/時間/中継/CT |
| フィールド | 83個の共通Box、中央2mの主戦場、3.6/5.4mの上段、8m構造物、左右迂回路。高台出撃と拠点表示を地表へ合わせる |
| 機体表示 | 元のメッシュを股/膝で分割、歩行/横移動/ダッシュ/ジャンプ/着地、射撃反動。表示で命中判定を変更しない |
| カメラ | 肩越しから壁手前へ寄せ、狭い場合頭部一人称。自機のみ隠し、復帰距離に余裕を持つ |
| 撃破/休止/結果 | 使用可能な機体・出撃先、CT/敵接近の制約、Tick停止/入力消去、結果/再戦。保存デッキは維持 |

UIは既存uGUI/TMPへ段階的に追加。1920x1080/Expand、インストール済みCJKフォント、1個のEventSystem。装備一覧は保持して切り替え、画面の再生成による参照破壊は行わない。非操作要素はRaycastを妨げない。

BOTは自身の状態、範囲内の可視接触、公開の地形/占領情報だけを使う。主力44は中央で武器別射撃距離を維持し、4強襲は外壁沿い、2占領役は内側通路へ。BOTの自軍初期本拠点だけを役割通路へ合わせ、人間の出撃先は変えない。被ロック時点で左右回避/共通ブーストに反応する。偏差は連続視認した位置から推定した65%を使い、遠距離の回避を可能にする。低HPまたはロック保持者からの実被弾で退避を継続し、公開地形の遮蔽/有限ポッドまたは自軍補給でHP/盾を回復、2.5秒無被弾で復帰する。敵の隠れた位置/IDを被ロック警告へ含めず、人間は警告だけで退避を強制しない。溜め取消は共通UnitCommand.CancelHeldAttackを使い、開始済み格闘の硬直は消さない。敵全位置の無条件公開、人間操縦、自動反撃は禁止のまま。

保存はApplication.persistentDataPath、有効な旧デッキは保持。不正データも保存操作まで元ファイルを残す。UserTextへ書き込まない。Scene/PrefabはEditor APIで生成する。

受入では一覧選択、空き番号とホットキー、HP/格闘指定値、自由照準/ロック/散布/直進弾/円色、中央/側面、ジャンプ/壁際視点、高台出撃、モーション、結果/手動再出撃、保存再起動、Windows起動を確認。コード検査/100BOT試合を実機表示・人間の操作感・FPSの代用にはしない。具体値は[COMBAT_RULES.md](COMBAT_RULES.md)、起動は[PLAYABLE_GUIDE.md](PLAYABLE_GUIDE.md)。

最新拡張（SUPPORT-08〜MELEE-09）: 味方HP回復FAと盾/弾薬ポッドを分離、補給不可装備を共通補給から除外。BattleFeedbackの実被害イベント→BattleFeedbackView/CombatImpactViewで命中・撃破を描画。BattleTeamContactsは明示ロック/範囲限定レーダーの時刻付きチーム接触だけを保持、1.7秒のHP表示とマップ共有へ接続。RadarRangeにはCanvasRendererを明示し、カスタムGraphicもRequireComponentで必須化。BattleBoostは通常回復/OH/使用可否を共通管理、通常760/D格2280と連続突進・補間姿勢へ改修。Claude追加の参戦/機体制作メイン画面と重量フレーム/7テンプレートを保持し、画面ハイライト/GLB/重量機脚分割を統合修正。詳細と未実機項目は[引渡し](reviews/GPT_UI11_HANDOFF.md)。

LOCK-10/SUPPORT-10: TargetLockSelectionは範囲/LOS/画面内で絞られた候補だけを受け取り、敵機優先→角度/距離順を安定決定する純C#選択器。PlayableTargetLockが入力と設定保存/読込、候補抽出、世代ID検証、取得時1回の赤吸着を担当。設定はデッキ保存と別のmechabattle-controls-v1.json。BattleObjectTargetsが設置物のLOS/ロックと実損害・破壊を管理し、同一配列枠の新設置へ旧損害/ロックを継承しない。ポッド3分/レーダー15分、耐久で破壊可能。専用設置メッシュと種類/HP菱形を接続。ObjectDestroyedは機体撃破数を増やさない。新規28純C#試験は実行済み、設定ボタン/実メッシュ生成のUnity向け試験はコード追加・静的検査済みでTest Runner未実行。

UI-11/PREVIEW-11: 制作と参戦準備のプレビューはHangarPreview（31層/1024×768/専用カメラと照明）→uGUI RawImageへ表示。主カメラは常に全画面で、非戦闘時はmask0/戦闘Sun無効、制作/参戦背景は不透明。モデル境界球に合わせカメラ距離を決め、回転中の切れを抑える。表示先は4:3 FitInParentで引き伸ばさない。スタジオは地形から離し、戦闘は31層を描かない。メニュー/戦闘ではスタジオを停止し、終了時RT/カメラ/ライトを解放。参戦画面の選択機体をSimulationの互換任意initialHumanDeckIndexへ渡し、初回出撃に反映する。出撃失敗通知は参戦画面にも表示する。Unity Test Runnerと見栄えは未確認。

SUPPORT-12/ALLY-12/MELEE-12: BattleFriendlyLocksが現在機体の回復FA/ポッド所持・LOS・出撃IDで味方ロックを判定し、敵専用ロックAPIを維持したままPlayableの候補とHUDだけを拡張する。BattleHealthDisplayの読取は味方の可視HP/敵の期限付き共有HPを分け、BattleFeedbackViewのCanvasGroupで味方全体をalpha0.5にする。AIへは渡さない。格闘の実損害確定からConfirmMeleeHitを一度だけ呼び、後隙×0.5・支払済み格闘ブースト50%返還。ミスや古い設置物には付与せず、OH/被行動阻害を解除しない。短縮された実時間をMeleePhaseへ反映する。独立27新規/計293試験と静的18アセンブリは成功、最新Unity表示/モーション/操作受入は未実施。

AIR-15: BattleAerialMotionが上昇/高度上限/滑空と空中速度の加減速を扱い、BattleTraversalの天井/足場/壁判定を共用する。UnitStateの空中基準/速度は出撃ごとに初期化。BotAerialTraversalは公開地形と自己/範囲内可視接触で高台越えと一部射撃役の短い上昇を入力へ接続。LocomotionWorldViewは縦速度で脚/胴体の姿勢を補間し、命中判定は変えない。既存HUDへ高度と実効ブースト容量を表示する。検証は独立335件・静的18アセンブリ・実設定100BOT。Unity描画/操作感/FPSは未確認。ARの欠損表示モジュールも補修し19部品/8構成を幾何検証。
