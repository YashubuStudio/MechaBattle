# 最小プレイ版の設計と受入条件

範囲: Windows x64、オフライン1人+99BOT、100操縦枠+各軍1指揮官枠、各軍3本拠点。MasterPlan FR-001/101/201/401–404/408/501/801/805と機体構想案v0.1に対応する最初の操作可能な一巡。指揮官の戦術AI、オンライン、装備大量追加、2019ミドルPC性能認定はこの版の完成と区別する。

| 画面 | 行動 | 遷移/ルール |
|---|---|---|
| 参戦準備 | 操作説明、青/橙選択、機体構築へ | 勝利目標と補給/CTを表示 |
| 格納庫 | 4枠選択、テンプレート適用、左右腕/主武器変更 | 全て同じBuildDefinition。重量/出力/性能/自動コスト/CTを即表示。無効構成は保存/出撃不可 |
| 出撃 | 保存済み4枠を検証して試合開始 | プレイヤーもBOTも同じ性能/CT/弾薬/補給 |
| 戦闘 | WASD、マウス照準、左射撃、Shiftブースト、E格闘、Esc中断 | TPS。HP/盾/弾薬/ブースト、両軍ゲージ、残り時間、拠点/CTを表示 |
| 撃破待機 | 使用可能なデッキ/出撃先を選択 | CT機は出撃禁止、敵のいる中継へ出撃不可、全CTなら待機 |
| 一時停止 | 再開/参戦準備へ | 戦闘入力停止、カーソル解放 |
| 結果 | 勝敗、拠点損害/撃破など、再戦/準備 | 試合状態を新規作成し、保存デッキは維持 |

保存はApplication.persistentDataPath配下。UserTextには書かない。UIは日本語、uGUI/TMP、1920x1080基準のCanvasScaler、InputSystemUIInputModuleを使う。画面切替時は不要な入力/レイキャストを停止。機体プレビューは実際の部品構成を表示し、敵味方色は試合側で決める。

受入: 保存→再起動読込、構成差の戦闘反映、Human/BOT共通CT、初期100生存、撃破後枠維持、結果/再戦、入力ロック/解除、画面外ボタン無し、欠落参照無し、Windowsビルド起動を確認する。未実行項目は完了扱いにしない。
