## 更新を取り込む

1. Playを停止し、開いたシーンを保存。必要なら **Assets > Refresh** を実行し、コンパイルを完了させる。
2. 初回のみ **MechaBattle > Playable > Generate and Open Playable Scene** を実行し、MechaBattle_Playable.unityでPlayする。既存Playableは今回の更新でシーン再生成不要。そのままPlayする。旧P0シーンは回帰用として残す。
3. 最初の画面で「参戦」または「機体制作」を選ぶ。機体制作では青/橙と4機デッキ、左右腕/装備の一覧から部品を選ぶ。参戦画面は汎用機/専用機とコスト、選択機体のプレビューを表示する。初回出撃はここで選んだ機体を使う。右側のマップで自軍本拠点をクリックし、出撃先を選ぶ。
4. 射撃7種/格闘/HP回復FA/盾・弾薬ポッド/設置レーダー/地雷/グレネードを最大3装備。任意2枠は「なし」も可能。編集時に空き番号を詰め、ホイール・1〜3と表示を一致させる。
5. 性能/容量/コスト/CTを確認し保存/出撃。旧有効デッキを保持するため、旧1装備のままなら追加装備を選ぶかテンプレートを適用する。

## 操作

| 行動 | 入力 |
|---|---|
| 移動・照準 | WASD・マウス。ロック後も自由照準 |
| ジャンプ/上昇 | **Space**。短押しジャンプ、保持・空中押し直しで上昇。離すと落下 |
| ダッシュ/滑空 | **Shift＋WASD**。地上はダッシュ、空中は落下を抑えた滑空 |
| しゃがみ | **左Ctrl保持**。地上で静止中に使用。移動/ジャンプ/ブースト/格闘で解除。帰投中は自動でしゃがむ |
| 装備切替 | ホイール、1〜3 |
| 使用 | 左クリック。FA/ビーム保持、SA/単発/設置/投擲は押し直し、チャージは保持→解放 |
| 手動ロック/解除 | 右クリック。黄範囲内で取得、赤範囲内の手動取得時だけ瞬間的に吸着 |
| ロック対象切替 | **Tab**。設定の「中心優先」または「距離順切替」で取得/切替 |
| 装填 | R。空弾倉は自動装填 |
| 格闘型 | Qで通常/連撃/D格/D連撃/チャージ |
| 手動格闘 | 格闘装備中の左クリック、またはE。ブースト移動中はD格（連撃型はD連撃）。Shiftだけの静止では切り替わらない |
| 戦術マップ・戦略支援 | **M**。核は自軍本拠点付近への要請、妨害/広域レーダーは地点指定で発動。M/Escで閉じる。地図中も戦闘は進行 |
| 核の拾得・手放し | **F**。近くの味方核を拾う。運搬中は手放す |
| 核の起動 | 運搬して**着地後に左クリックを押す**。その地点で3秒予告後に爆発。空中での押しっぱなしでは起動しない |
| 緊急帰投 | **B**。地上で6秒待機。移動/攻撃/被弾等または再Bで中断。完了後に出撃先を選ぶ |
| 休止/再開 | Esc。地図/装備一覧ではその画面を閉じる |
| 撃破後 | CTが明けた機体を選び、マップの本拠点/確保中継をクリックして出撃 |

旧Spaceダッシュ/Shiftジャンプは今回の明示指定で変更した。旧赤ロック継続追尾も置換した。

## 見方・戦い方

標準HP2000/盾900、補強腕1本でHP2600、2本で3200。重量フレームHP2650、補強腕2本で3850。通常格闘760、D格2280を基本とし、腕由来チャージは標準腕で威力500・範囲拡大、補強腕で威力550〜3000。近接は盾貫通/高DPと接近リスクを持つ。射撃は物理射程>黄ロック>赤ロック。敵へのロックは攻撃武器の散布をなくすが弾道を誘導しない。遠距離では相手の移動を読んで先へ撃つ。

照準は広い円と中央十字。外周円が黄なら中心に敵がいるものの命中確度に不足があり、緑なら現照準・散布・銃口射線で静止相手に当てられる状態。ロック相手の胴体へ菱形、下に距離と赤/黄の状態を表示する。ロック後も自分で追い、黄から赤に入るだけで追加吸着はしない。

左上の戦闘ミニマップは、出撃先選択・戦術マップと同じ上空地形背景を表示する。全4マップで建物・足場と地形の縦横比を反映する。水色線は二層都心では地下経路、再生工廠では低地の経路を示す。拠点・自機・味方・共有索敵・レーダー範囲を同じ縮尺で重ねる。マップ切替で背景も切り替わる。

HUDは選択中の装備を3枚のカードで強調し、射程/黄/赤/弾速、残弾/装填、格闘型、HP/盾/ブースト/DPを表示。被弾時は短く赤く反応し、低HP/行動阻害を文字でも表示する。明るい弾体・軌跡・発射閃光を追加した。敵にロックされると上部に「被ロック ×人数」と警告音を出し、その状態で被弾すると赤い退避・回復案内を表示する。人間の退避操作はWASD/Shiftで自分で行う。

中央に主戦場の高台と遮蔽物、左右に少数の迂回路を配置。壁は弾/爆風/移動を遮る。段差へジャンプでき、高台中継からの出撃も地表に合わせる。壁際のカメラは頭部へ寄り、必要なら一人称へ切り替わる。機体には歩行・膝・ダッシュ姿勢・ジャンプ/着地・反動の簡易モーションがある。

敵建屋の20m内へ入りコアを攻撃する。反撃も20m内、標準HPの70%/5秒。主力BOTは中央で射撃距離を保ち、4強襲は外壁沿い、2占領役は内側通路へ回る。最後の建屋進入には中央からの射線を切る壁と歩行通行口がある。敵のいる中継からは出撃できず、全機CT中は待つ。BOTは被ロック警告でブースト/左右回避に反応し、ロック保持者の実攻撃が当たると攻撃を中断し、近くの遮蔽物で有限ポッドを使うか自軍本拠点へ帰還する。HP/盾が回復し2.5秒無被弾で復帰する。味方本拠点でHP400/盾180毎秒・補給可能な装備の弾薬を補給する。時間切れでも残ゲージから勝敗を決め、結果から再戦できる。

## 命中・支援・索敵

命中は中心の×、HP/盾の実被害数値、火花と確認音、撃破は大きな文字と専用音・破裂で区別する。空振りや別人の撃破では自分の通知を出さない。回復FAは味方へ照準を合わせて左クリックを保持し、緑の射線でHPだけを回復する（45HP/発、0.15秒指定は50Hzで0.16秒、射程65m、30/180発）。盾/DP回復や蘇生はしない。

ポッドは盾160/秒・弾薬6/秒を主に、HPは40/秒。8m/180秒（3分）、3回・所有者3個まで、壁越し無効。**ポッドとレーダーは本拠点でも弾数補給不可**。レーダーは90m/900秒（15分、従来の20倍）、3回、所有者3基。味方のマップへ範囲を表示し、0.5秒ごとに範囲内の敵位置を共有する。HPや射撃ロックを自動取得しない。

明示ロックした敵機の位置・頭上HPは味方全体で共有し、最後の有効ロックから**1.7秒**残す。解除後は最後に観測した値を保持し、期限切れ/撃破/再出撃で消す。頭上ゲージは自分から見える相手を対象とし、遮蔽物越しはマップの最終位置を使う。レーダーが検知を続けてもHP表示だけを延長しない。

ブースト移動消費は17.5/秒、通常の地上回復100/秒。0でオーバーヒートし、通常姿勢では回復20/秒・満タンで解除。地上静止でしゃがむと通常回復200/秒・OH回復40/秒になり、満タン前には解除しない。それまではダッシュ/ジャンプ/滞空ブースト/ブースト消費格闘を使えない。歩行と通常格闘は可能。空振り時の通常格闘は発生0.06/後隙0.10秒、D格は0.12/0.16秒、追加CTは0.15/0.20秒。突進を発生中へ分散し、歩行/ダッシュ/格闘の姿勢を補間する。

## 設置物ロック・ロック方式

メインメニュー、参戦準備、Esc休止画面の「ロック方式」で **中心優先 / 距離順切替** を選ぶ。中心優先は画面中心へ最も近い可視敵機、距離順切替は近い可視敵機からTabで順に選び、一周する。右クリックは取得/解除。候補は黄範囲・画面内・遮蔽なしに限定し、敵機を設置物より優先する。候補の敵機がいない場合、敵ポッド/レーダー/地雷も同じ方式で選べる。

敵設置物の菱形には種類・距離・HPを表示し、現在ロック中の敵設置物は自分のマップにも表示する。ポッドHP1800、レーダー900、地雷450。射撃/爆風/格闘で破壊でき、地雷の射撃破壊は誘爆しない。設置物の破壊は機体撃破数へ加算しない。破壊/期限切れ/上限置換/範囲外/遮蔽で解除し、新しく置いた同じ場所の物へ古いロックを引き継がない。設置後は専用モデルを使う。

ロック時の散布0・赤取得時だけ瞬間吸着・以後の自由照準は敵設置物でも共通。方式はApplication.persistentDataPath/mechabattle-controls-v1.jsonへ保存する（デッキとは別）。

## 味方HP・回復ロック・格闘命中ボーナス

視界内の味方HPはロックなしでも半透明で表示する。現在出撃中の機体に回復FAかポッドを持っていれば、右クリック/Tabで味方もロックできる。回復FAを手に持っている間は味方だけが候補になる。所持FAなら60m、ポッドだけなら8mが味方ロック範囲。予備デッキの装備は対象外。味方ロックは緑の菱形と距離/HPで示す。回復FAの25m以内で手動取得した瞬間だけ吸着し、その後は自分で合わせる。味方ロックで攻撃武器の散布は消えない。

格闘の後隙を短縮し、実命中した段はさらに半分にする（通常は50Hzで約0.06秒、D格0.08秒）。消費した格闘ブーストも半分返るため、D格は30を支払って命中時15返還。空振りは後隙0.16秒/消費30のまま。同時に複数へ当てても返還は1回、0で発生したOHは返還では解除しない。開始時には30が必要。威力760/2280と追加CT0.15/0.20秒は維持する。

今回のSUPPORT-12設定は直接参照するJSONへ反映済み。既存PlayableシーンならPlay停止→Assets > Refresh→コンパイル完了→Playで取り込める。Unity Test Runnerと実画面の味方ゲージ/ロック/短縮モーションは未実施。独立C#293/293と静的18アセンブリ、実設定100BOTの完走は確認済み。詳細は[引渡し](reviews/GPT_AIR15_HANDOFF.md)。

## AIR-15：上下移動と空中ダッシュ

Space短押しは小さなジャンプ、保持すると燃料を使って上昇する。空中で押し直せば落下を制動して再上昇できる（追加ジャンプの瞬間加速ではない）。上昇速度は最大6m/s、上限は離陸した面から10m。高台から出れば高台を基準とする。上限では保持で高度を維持し、ブーストは消費し続ける。

Spaceを離してShift＋WASDなら、横方向へダッシュしながら毎秒2.5mを目安に滑空降下する。Space＋Shift＋WASDで斜め上へ移動し、両方を離すと通常の重力で落下する。空中の加速・切返し・停止には短い慣性がある。天井/壁は通過せず、空中回復と無限上昇はない。離陸12、上昇/高度維持25毎秒、横ダッシュ17.5毎秒。0でOH、着地後は通常姿勢20毎秒・しゃがみ40毎秒で実効満タンまで回復して解除する。人間容量130/BOT100を維持し、HUDも実効容量と現在高度を表示する。

BOTも同じ資源/衝突/移動で高台を越える。一部の射撃役は視認中だけ短い上昇を織り交ぜ、他の主力は地上の射撃線を保つ。上昇/降下で脚と胴体、空中旋回で傾きを滑らかに変える。

## DEPLOY-16：マップから出撃先を選ぶ

参戦準備では右の地形マップ上の自軍本拠点（■）をクリックし、黄色の枠と「出撃先」の名前を確認して「出撃する」を押す。初回は各軍3本拠点から個別に選べる。陣営を変えると、変更後の自軍本拠点が初期選択される。

撃破後も機体と出撃先を個別に選ぶ。マップの本拠点（■）または占領済み中継（◆）をクリックし、「選択した場所へ出撃」で確定する。敵軍/未占領/敵接近中の中継は選べず、使用不可の理由を表示する。選択後に中継が利用不可になると出撃ボタンを無効化し、要求後の待機中に奪われた場合も別の拠点へ自動変更せず待機する。別の有効拠点を選び直す。機体CTと再出撃待ち時間は維持する。

上が北。地形・高台・自軍位置と共有索敵の敵最終位置を表示し、未観測の敵位置は表示しない。任意の地面への出撃ではなく、選択した有効拠点の既存散開範囲から出撃する。通常のマップと拡大マップの寸法に合わせて縦横比を維持する。

Play停止→Assets > Refresh→コンパイル完了→既存PlayableでPlay。今回のUIは起動時生成のためScene再生成は不要。最新の検証と未実機事項は[出撃マップ引渡し](reviews/GPT_DEPLOY16_HANDOFF.md)を参照。

BOTは、実際に発行した移動指示と自分の3D座標変化を比較します。約2秒動こうとしても進めていなければ、公開された地形を調べて側方へ回避し、経路を計算し直します。進行方向へ抜けられる回避を優先します。2回試しても抜けない場合や、回避した後に同じ閉塞地点へ短時間で繰り返し戻る場合は、着地・攻撃終了後に通常の緊急帰投へ移ります。意図的な停止、射撃位置の維持、移動できている旋回、格闘硬直や行動阻害、人間操作を自動復旧の対象にはしません。検知の開始時期は個体で少しずらします。

帰投中は移動・攻撃を止めますが、被弾等で中断する通常ルールを維持し、すぐに帰投の開始/中断を連打しません。帰投を完了したBOTは同じ機体を通常速度で補給し、HP/盾/燃料と補給可能な弾が戻ってから別の生きた自軍本拠点へ再配置します。撃破やCTのリセット、補給禁止のポッド/レーダー弾の補充は行いません。核運搬中のBOTは帰投せず、回避を続けます。人間の帰投後の出撃先は従来どおり自分で選びます。

しゃがみは左Ctrl保持で、地上静止中に使えます。通常の射撃は可能です。移動/ジャンプ/ブースト/格闘・行動阻害で立ち姿勢へ戻り、帰投チャネル中はキーを押さなくてもしゃがみます。腰を下げ、膝・胴体を滑らかに曲げ、カメラも頭の高さへ追従します。今回のしゃがみは姿勢と燃料回復を扱い、衝突寸法は変えません。

しゃがみ中のブースト回復は2倍です。通常は100→200/秒、オーバーヒート中は20→40/秒。空中での回復や満タン前のOH解除はありません。Play停止→Assets > Refresh→コンパイル完了→新しい試合で反映し、Scene再生成は不要です。実機/Native/Windows/FPS・GCの状況は[引継書](reviews/GPT_STUCK31_HANDOFF.md)を参照。


## TACTICS-32：小隊長カラー・両軍の戦術判断

特殊塗装を戦闘中に使えるのは小隊長機だけです。現在は各軍2小隊×4機で、陣営内の先頭と5番目の操縦枠が小隊長（全体slot0/4/50/54）です。一般兵と小隊員は青/橙の通常装甲色になります。肩・膝・頭頂等の陣営識別色は特殊塗装でも維持し、格納庫の保存塗装は書き換えません。現在の人間操縦枠は各軍の先頭なので、小隊長として選択した塗装を使えます。

小隊BOTは公開された中継の目標を共有し、最大2秒の集合待ちと、36m以上離れた場合の合流を行います。帰投中・重傷の仲間は合流先に選びません。目標を約8秒保持し、占領が済めば切り替えます。中継付近の味方や他の目標割当が多い場合は別の拠点も選び、全員が同じ地点へ殺到するのを抑えます。既存の単独裏取り役は中継確保に呼び戻しません。交戦・回復・補給・スタック復旧は個体側が優先します。人間の移動や攻撃を自動操作しません。

レーダー等で報告された同一周辺の敵には、迎撃役を原則2機まで割り当て、他の防衛BOTは別の自軍本拠点を見ます。索敵情報の失効、認識の遅れ、射界・遮蔽は維持します。地図を読む割合の設定は共有索敵の利用率で、小隊の公開拠点目標の共有とは別です。レーダー役は既存の有限弾を使い、最小設置間隔を守りながら未カバーの場所へ最大3個を展開します。

反映はPlay停止→Assets > Refresh→コンパイル完了→新しい試合。Scene再生成は不要です。検証結果と実機未実施事項は[Claude向け引継書](reviews/GPT_TACTICS32_HANDOFF.md)を参照。
