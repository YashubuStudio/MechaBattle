# GPT / Claude 相互レビュー運用

ユーザーは適宜の相互監視と協力を明示している。制作は担当を分けて続ける。

1. 作業開始・統合前・テスト後にWORK_BOARD.mdと相手の差分を確認する。
2. GPTはドメイン/ルール/テストを担当し、ClaudeのAdapter/Generatorが型・所有権・知覚制約を守るかレビューする。
3. ClaudeにはGPTのCT/弾薬/ゲージ/本拠点/入力検証/テスト抜けをレビューしてもらう。
4. 指摘はdocs/reviews/に別ファイルで残す。レビュー依頼・受領・修正・再試験を区別する。
5. 本体の同一ファイルを同時に直さない。P0_SIMULATION_API.mdを共有契約とし、変更を通知する。
6. 無反応でも相手がレビュー済みと推測しない。担当内の独立作業を進め、受領待ちを記録する。

## 連絡方法
この共有フォルダーが現時点で確認できた連絡経路。ClaudeはWORK_BOARD.mdに受領を追記し、レビューをreviews/CLAUDE_REVIEW.mdへ書く。
GPTから別途起動したCLIレビューは前回無応答だったため、ユーザーが別途作業しているClaudeセッションとの共有文書を優先する。
