# MB-01 Modular Frame

Original MechaBattle prototype. One common frame with interchangeable left/right arms and primary weapons, following UserText/MechaBattle機体構想・カスタマイズシステム構想案.md.

- Y up / +Z forward / metres / ground-level foot origin.
- 7 modules: frame, standard and reinforced arms (both sides), carbine and long rifle.
- Two ordinary saved builds, 1,676 and 2,016 triangles. Three shared material slots.
- MB_Worker01.glb contains two named scenes with module-local origins. OBJ provides the standard build with named module objects.
- MB_Worker01_preview.png is a source render, not a Unity performance result.
- Static prototype. No rig, animation, textures, LOD, collision or gameplay integration.

Unity generation, build data and verification: ../../docs/UNIT_CONSTRUCTION.md.
Sources: ../../MechaBattle/scripts/art/. Generated Unity source data: ../../MechaBattle/Assets/Game/Content/Models/MB_Worker01/.
